# JARVIS WEB LAB

Base del experimento JARVIS WEB LAB construida con Next.js, App Router y
TypeScript.

## Requisitos

- Node.js 20.9 o superior
- pnpm (recomendado) o npm

## Ejecutar en local

Instala las dependencias:

```bash
pnpm install
```

Inicia el servidor de desarrollo:

```bash
pnpm dev
```

Abre [http://localhost:3100](http://localhost:3100) en el navegador.

Si prefieres npm, puedes usar `npm install` y `npm run dev`.

## Comprobar el proyecto

```bash
pnpm lint
pnpm build
```

## Alcance actual

Esta primera fase incluye únicamente una landing estática. No incorpora IA,
CMS, autenticación ni base de datos.
